About us

A hug in café form

The name

cwtch rhymes with "butch" · Welsh A cuddle. Also a cosy little nook to tuck yourself into.

Cwtch & Cake is a student café in Cathays: the kind of place you'd want a few minutes from your lectures. Good coffee at student prices, Welsh cakes cooked on a bakestone every morning, a plug at every seat and Wi-Fi that doesn't drop.

Most of it is walk-in. You can book a study room for a group project, the big table for your society, or a Saturday class, and the home page tells you how busy we are before you walk over.

How this website works

The café is made up, but everything you can click is real, running on Amazon Web Services and built entirely from code.

PartHow it's done
This websitePlain HTML, CSS and JavaScript in a private S3 bucket, served worldwide by CloudFront with strict security headers (rated A+ by Mozilla Observatory)
Menu, bookings and reviewsAPI Gateway and small Python functions on AWS Lambda, storing everything in DynamoDB
No double-bookingEach booking and its slot counter are saved in one DynamoDB transaction, so two people can never get the last room
Kind reviewsA whole-word filter that sees through disguises, then a person approves every review
The admin pageAmazon Cognito login with an authenticator app, checked again by API Gateway and the function itself
Watching it runCloudWatch dashboards and alarms that email the owner if anything breaks
Built from codeTerraform for every AWS resource, deployed by GitHub Actions with no stored passwords
